# Booth Homelab Design System

The shared look and feel for Warren's self-hosted apps. Every new app pulls this repo; existing apps move to it when they're next given UI work. Modelled on Marc's Design Uniformity spec (Encore).

## Category accents (from the links page)

| Category | Accent | Example apps |
|---|---|---|
| Media | `#F5B82E` amber | Media finder, BookHound, TubeYard |
| Network & infrastructure | `#3B82F6` blue | Switchboard, WarrDash |
| Home | `#22C55E` green | Home Assistant panels |
| Monitoring | `#A855F7` purple | servermonitor |
| Dev & automation | `#EC4899` pink | n8n tools |
| Apps & tools | `#14B8A6` teal | Wine Tracker, shopping list |
